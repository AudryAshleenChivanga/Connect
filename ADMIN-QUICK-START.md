# 🚀 Admin Quick Start Guide

## Welcome to Ashletech Connect SRHR Admin Panel!

This guide will help you get started with managing your SRHR platform content.

## 🔐 Accessing Admin Panel

### Option 1: Secret Access (Recommended)
1. Go to your main website (`index.html`)
2. **Triple-click the logo** in the top navigation
3. Admin panel will open in a new tab

### Option 2: Direct Access
1. Open `admin.html` directly in your browser
2. Login with these credentials:
   - **Username:** `admin`
   - **Password:** `ashletech2025`

**Security**: The admin panel is hidden from public navigation for security reasons.

## 📊 Dashboard Overview

After logging in, you'll see:
- **Total Resources**: Current number of health resources
- **Categories**: Number of different resource categories
- **Recent Activity**: Log of recent changes and additions
- **Quick Stats**: Usage metrics and engagement data

## ➕ Adding Your First Resource

1. Click **"Add Resource"** in the navigation
2. Fill in the form:
   - **Title**: "HIV Prevention and Testing"
   - **Category**: Select "Sexual Health"
   - **Description**: Write a detailed description
   - **Icon**: `fas fa-shield-virus` (or any FontAwesome icon)
   - **Tags**: `hiv prevention testing health`
3. Click **"Save Resource"**

## 🔍 Managing Resources

### Finding Resources
- Use the **search bar** to find specific resources
- **Filter by category** using the dropdown
- Sort by clicking column headers

### Editing Resources
1. Find the resource in the table
2. Click the **Edit** button (blue)
3. Update the information
4. Click **"Update Resource"**

### Deleting Resources
1. Find the resource in the table
2. Click the **Delete** button (red)
3. Confirm deletion in the popup

## 💾 Data Management

### Export Your Data
- Click **"Export"** to download all resources as JSON
- Save this file as backup
- File name format: `ashletech-srhr-backup-YYYY-MM-DD.json`

### Import Data
- Click **"Import"** to upload a previously exported file
- Select your backup JSON file
- All resources will be restored

## ⚙️ Settings

### Change Admin Password
1. Go to **Settings** tab
2. Enter new password in **"New Password"** field
3. Click **"Update Settings"**

### Update Platform Info
1. Go to **Settings** tab
2. Update **Site Title** and **Contact Email**
3. Click **"Save Settings"**

## 📱 Viewing Your Changes

- Click **"View Site"** to see your main website
- All changes in admin panel appear immediately on the main site
- No need to refresh or restart anything

## 🏷️ Best Practices for Tags

- Use lowercase letters
- Separate with spaces
- Be specific: `contraception pills birth-control`
- Include synonyms: `periods menstruation menstrual-cycle`
- Add location if relevant: `nairobi kenya clinic`

## 🔄 Staying Updated

1. **Regular Backups**: Export your data weekly
2. **Content Review**: Check resources monthly for updates
3. **User Feedback**: Monitor contact form submissions
4. **New Topics**: Add emerging health topics as they arise

## 🆘 Need Help?

- Check the main `README.md` for detailed documentation
- All data is stored locally in your browser
- Clear browser data will reset everything (keep backups!)
- Resources auto-save as you work

## 🎯 Pro Tips

- **Batch Operations**: Add multiple similar resources at once
- **Consistent Icons**: Use similar icon styles for same categories
- **Detailed Descriptions**: Include actionable information
- **Regular Updates**: Review and update content quarterly
- **Backup First**: Always export before major changes
